# M1.f：首轮反事实结算

普通主会话采纳后，准备阶段冻结模型、历史与缓存参数，将规划器 `remainingTurns` 设为 1，单独计算原窗继续的首轮预计成本。此基准与原多轮预览分开保存。新窗承载轮正常结束且 CLI 报告美元费用时，比较该首轮估价与该承载轮费用，差额夹零；这是**反事实估算**，不是测得的真实节省。估算依赖历史平均调用、token、输出、缓存和知识包价格，不能预知未来输入、工具调用、模型行为或实际计费，数值可能偏高或偏低。

同窗指令并不能证明上下文被压缩，因此即使该轮有费用也只留下未结算事件；新窗缺美元费用也保持未知，零费用则保留为有效的已报告值。动作的 `actual_saving_usd` 是历史字段名，M1.f 的有值记录是上述反事实差额，并非可观测的实际节省。事件保存 action / 目标消息、方法、首轮基准、实际报告费用、规划参数及原因。原子写入事件和动作，重复相同请求幂等，目标不匹配、状态不符或重复不同结果拒绝；失败/取消不能覆盖已记录的完成。未完成、重启中断或 RPC 响应丢失不能自动推断完成。

看板只累加已结算、费用有效的新口径 CONTEXT 事件；未知和旧口径事件保留在账本但不计入。ASSIGNMENT / DIRECT 同样排除未结算或未知成本。看板总额和上下文行标明估算，展开说明列出局限。原来的上下文节省历史可能使用多轮减单轮，不能与新口径合并；本节点不修改历史记录。

适用范围仍是 M1.e 的普通主会话，不接入共享 Runtime 或任务窗，不开放原生 compact。自动化测试使用离线模拟；真实桌面与模型验收留给 M1.g。一次完成事件后的异步持久化失败会向会话提示；进程崩溃时没有自动补算或追认的恢复机制。

离线验证：前端 81 文件 / 528 项、上下文库 40 项、存储库 42 项，生产构建、桌面 crate check、i18n、IPC 接线与测试隔离检查通过；覆盖首轮差额、无节省、负差额、零费用、缺费用、同窗未知、目标绑定、重复与冲突、旧口径过滤。首次存储测试使用不完整的测试数据库导致缺少关联表，改为完整迁移后通过；不代表真实桌面或模型验收。
