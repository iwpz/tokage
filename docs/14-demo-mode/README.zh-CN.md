# 演示模式

[English](README.md) | **中文**

在 **设置 → 规划与模型 → 演示模式** 开启。侧栏出现 `demo_project` 和 `demo_work`。点击“打开演示”可直接进入预置对话；打开计划视图审阅，再点击“确认执行”。

演示不需要安装或登录模型 CLI。预置规划显示 Fable 5.1，实际来源明确标为 Mock。后续执行通过原有任务调度器流式返回脚本内容，不调用真实模型。

## Pocket Tasks 剧本

演示仓库包含一个无需安装依赖的 JavaScript 任务看板模块。需求、规划、任务说明、报告正文和验收反馈均有中英文版本；任务 ID、依赖和代码共用。

1. T1：数据结构与持久化。
2. T2：依赖 T1，新增、完成切换、筛选与计数。
3. T3：依赖 T1，任务视图与计数展示。
4. T4：依赖 T1，存储回归测试。
5. T5：依赖 T2、T3，应用集成。
6. T6：依赖 T4、T5，综合回归测试。
7. T7：依赖 T6，审查契约与交付文档。

T2、T3、T4 可以并行，实际并行数遵守执行设置。执行沿用现有解析、校验、匹配、上下文、报告、修复、Git 与交付流程。审阅时可以修改计划和模型。演示模型目录独立于真实 CLI 的安装和授权状态，普通项目的配置不变。

报告的机器协议标题和 `None` 哨兵保持英文，这是现有报告解析器的格式要求；正文按剧本语言返回。

## 四个场景

- **完整流程成功**：七个任务完成并进入现有交付流程。
- **首次验收失败后修复成功**：T2 首次实现故意错误地计算剩余数量，模拟验收失败；修复轮次写入正确实现，重新验收通过。
- **执行失败**：T3 返回本地化错误，依赖任务受阻，进入现有错误处理流程。
- **慢速响应**：T3 等待 30 秒，可以测试取消、继续和响应展示。其余任务正常执行。

选择场景后点击“创建 / 重置演示”才会应用到新运行。语言在创建会话时固定；切换应用语言后重置，可得到另一种语言的完整剧本。流式间隔对后续轮次生效。

## 数据与执行边界

- 桌面端每次重置创建新的 `debug-workspaces/demo/<run-id>/demo_project` Git 仓库；不会写入用户工程。仍需本机 Git。
- 演示文件真实写入，worktree、提交和合并真实运行。最终是否合并演示分支，仍由现有交付界面处理。
- **演示验收反馈是模拟的，不运行 `npm test`。** 生成的代码可在演示仓库中手动运行 `npm test`；开发集成测试会真实运行最终产物的 `node --test`。
- 演示项目、消息、计划、attempt 和 gate 记录使用现有应用数据库，不是独立数据库。来源被标为 Mock，不产生真实模型用量、成功率学习或节省记录。
- 演示会话 ID 和受 Git 跟踪的仓库标记共同约束后端路由。关闭演示或切换付费调试来源后，已有演示会话仍强制使用 Mock；缺少隔离仓库则失败。
- 关闭模式会隐藏侧栏项目，运行中的任务仍按原 Mock 路由结束。再次开启保留运行记录。
- 重置替换当前演示项目和会话；执行或验收中的演示必须先结束或取消。旧仓库保留在应用数据目录，便于排查，不自动删除。
- 浏览器预览使用内存文件和模拟 Git，不代表桌面端真实 Git 行为已经验证。

## 检查面板

演示工作区顶部的“演示检查”依据当前应用进程观测到的事件显示：

- 实际输出来源是否为 `DEBUG_PROVIDER/mock`。
- 上报的 token、API 调用和费用是否全部为零。
- 已观测到结束事件的轮次是否恰好结束一次。
- 已启动任务是否在上游完成之后启动。

尚未观测的内容显示“尚未观测”。重启后事件检查重新积累，不把缺少证据当作通过。检查面板不替代真实代码测试，也不证明厂商 CLI 兼容性。

当前没有预编审批、配额切换、合并冲突、格式修复或增量需求剧本；手工交互仍走现有实现，但不应据此声称这些分支已覆盖。

## 开发验证

```sh
npm run typecheck
npm test
npm run build
npm run check:i18n
cd src-tauri
cargo test -p tokage-native --lib chat::debug
cargo test -p tokage-native --lib chat::demo
cargo test -p tokage --lib debug_provider
```

上述命令不启用付费 live 测试。前端测试覆盖双语初始化、重置、普通项目路由隔离、无真实 provider 的规划与任务执行、依赖顺序、修复、错误与取消。Rust 测试覆盖后端强制 Mock、真实计划解析和匹配、双语报告解析、worktree、提交、合并，以及最终产物的真实本地测试。

共享剧本位于 `src-tauri/resources/demo/pocket-tasks.json`，同时被 TypeScript 和 Rust 加载。修改任务时应同步修改两个语言版本，并保留机器协议字段。
