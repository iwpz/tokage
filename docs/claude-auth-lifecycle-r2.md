# Claude 认证生命周期诊断（CLI-MGMT-R2）

2026-10-26 开始 R2a。范围：正常在线管理查询的本地脱敏诊断、明确认证拒绝分类、PTY 准备与结果阶段区分。普通扫描不启动 `claude auth status`，不写凭据、不改过期时间、不自动登录，不发模型 prompt。沿用既有官方 `/usage` 刷新链；本次不做真实换号、制造失效或后台监控。

停止与完成标准：完成离线安全/分类/进程回归、原生检查及本地提交；长期根因与自然过期/正常重启的当前版本实测另列待办。此前 G3e 已观察一次正常 access 过期由官方刷新，但不能解释用户报告的历次异常。

## 确认的问题及变更

原 `QueryFailure::cli` 未识别 `OAuth token revoked`、`token expired`、`invalid_grant` 和 `Not logged in` 等明确拒绝，可能回落为 Network。Claude PTY 只等待提示框、补全和完整额度；认证拒绝画面可能最终变为统一 Timeout。现在管理链只识别明确认证标志，返回固定脱敏错误；遇到拒绝时不继续键入或回车。普通准备超时保留 Timeout，并区分提示框、内置补全、结果阶段；无完整额度解析归为 InvalidData。

新增本地 `online-usage/claude-auth-lifecycle-v1.json`（应用配置目录内），最多 128 个事件，原子替换，Unix 文件权限 0600。仅原生正常授权管理查询记录；不新增 IPC 或网络端点。包含尝试编号、CLI 数字版本（从同路径检测缓存取得，否则 null）、观察时间、access/refresh 的 Missing/UnknownExpiry/Valid/Expired 及声明的到期时间、查询阶段、脱敏错误类别、最终状态和耗时。利用既有查询前后凭据读取，不额外启动 CLI 或读取钥匙串。

仅记录“凭据发生变化”的布尔值，不记录 Token、指纹、账号、组织、路径、原始 CLI 输出或错误。版本字符串须为三段纯数字，未知保持 null。记录跨应用重启保留；超过容量淘汰最旧事件，不保证无限历史。写失败只发固定警告，不改变查询结果或认证门禁。

`credentialsChanged=true` 只证明两次读取不同，不能单独证明刷新成功或谁触发了变化。需要同时观察原 access 已过期、后 access 有效、同身份复核通过及查询成功；外部并发操作仍可能影响判断。查询成功返回事件也不替代最终来源复核与持久化结果。缓存/退避/取消不冒充新查询成功，Finished 事件保留相应状态。若查询前来源不可用，只有最终状态，不编造凭据元数据。
