# Tokage CLI 开发计划

用户于 2026-10-21 明确暂停 10/20，并选择 CLI 首版覆盖完整链路：需求 → 规划 → 执行 → 审查 → 确认合并。这是独立产品能力，不是验收驱动，不计入可靠性样本。

## 边界

独立 Rust CLI workspace crate，不依赖 Tauri/WebView、前端 Store 或桌面数据库。复用 tokage-core / native / planning / orchestration 已有领域服务：原生适配器、沙箱能力、计划解析与校验、brief、门禁、范围快照、默认 Git 身份和精确源/目标合并。首版提供串行 DAG 调度，后续可扩展并行及统一桌面高层编排；不宣称与现有前端编排逐项等价。

CLI 使用独立、可指定的数据目录；公开命令管理运行记录和授权。不会读写桌面 UI 的 localStorage/数据库，不修改账号、Git 配置，不加入样本 ID 特判。默认不发送请求；模型调用仅由公开规划/执行命令触发。CLI 测试使用测试文件中的进程 fixtures，真实模型验收另行登记。CLI HOME 不因独立运行目录自动隔离。

## 里程碑

- [ ] cli1a：命令基础、JSON 输出、帮助及退出码、运行目录、环境/仓库/计划只读命令。
- [ ] cli1b：需求登记、真实规划入口、计划检查与精确摘要授权；授权绑定模型、任务范围和确认的命令。
- [ ] cli1c：无头串行 DAG、任务工作树、原生流式事件、范围/门禁校验、默认身份提交和任务集成；失败保留。
- [ ] cli1d：独立只读审查、最终门禁、精确候选证据、显式确认合并；dirty/stale target/source 拒绝。
- [ ] cli1e：状态/事件/取消/显式重试、CLI 进程端到端离线回归、安全拒绝用例、用户文档与测试隔离规则更新。

## 首版交互契约

`tokage` 为 CLI 安装后的命令；桌面现有可执行目标保持独立。`--data-dir PATH` 使用独立运行空间，`--json` 输出机器可读结果；运行事件保存为 JSONL。`run create` 登记需求和指定 Provider/model，`run plan` 付费规划，`run approve` 精确确认计划及写入/信任授权，`run execute` 执行并审查至待合并，`run merge` 显式确认源/目标后合并。允许用户导入普通计划文件；导入不能跳过同一套计划校验、授权和后续门禁。所有修改限定在隔离 worktree，主 checkout 仅在 merge 命令发生改变。

每个完成并验证的子节点自动本地提交；不自动 push。不把离线 fixtures 通过写成真实模型通过，不恢复任何旧桌面验收入口。10/20 恢复前应重新登记实际采用的产品入口和协议，不重写旧登记或证据。
