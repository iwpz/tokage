# U2：身份绑定、用量契约与共享查询服务

日期：2026-10-24。实现基线：`cee222d`。依赖：[U1 原生权限](cli-usage-u1.md)；范围：[U0 冻结](cli-usage-u0.md)。本节点完成共享基础设施与离线验证，不把 U3 的各家适配、U4 的完整交互或 U6 的实机查询标为通过。

## 数据与兼容性

新增 `usage_query::contract`，AccountSnapshot schema 为 2；旧 UsageSnapshot 仍可读取 / 展示。新快照包含 provider / backend 范围、可空 endpoint / 脱敏标签 / 组织 / 工作区、本机不透明身份键、身份代际、采集时间、有效期和来源。

窗口具有独立 id、scope、period、可空时长 / 已用百分比 / reset，百分比固定 0–100。允许同周期不同模型并存；模型额度不能未经解释当作整个 Provider 的额度。credits、请求数和货币数量独立保存；数量使用十进制字符串，货币保留 currency，不求和、不换算、不经浮点数丢失精度。

`QueryOutput` 是适配器中立的输出：CLI 与 HTTP 均可提交窗口、数量及可选旧展示数据，再经过同一验证、身份接受、持久化与失败策略。旧 CLI 输出桥接为 `unclassified` 窗口，使用周期与重复序号区分，不假定旧解析器丢失的模型 / 账号范围；这些旧窗口可以展示，但不能驱动 Provider 级调度。

QueryResult 分开保存本次 status / error / attemptedAt / nextRetryAt 和 latestSuccess。失败不刷新旧数据时间；旧成功数据标记 fromCache，过期不画成 0%。身份未知时，历史快照保留为历史数据，不升级成当前账号。异常比例、NaN、空数据、重复 id 和非法金额不能替代有效快照。

查询摘要及最近失败写在普通 app_config_dir 的 `online-usage/snapshots-v2.json`，不写任务消耗账本。只保存选取后的摘要，不保存厂商响应全文、CLI 终端全文、认证头或凭据。读取和写入均有 1 MiB 限制、原子替换与文件同步；保存失败回退到之前成功摘要并报告失败。

## 身份与外部变化

身份键使用本机 CSPRNG 产生的 32 字节秘密，通过 HMAC-SHA256 对来源字段计算不透明标识；秘密单独存于 `identity-salt`，不序列化给前端或作为账号标签。身份状态不以套餐名、Provider 名、旧日志或历史 token 用量推断。秘密损坏时查询失败关闭，不借用旧身份。

当前可接入的身份管理命令：Claude `auth status --json`、Cursor `status --format json`、Copilot 已有 SDK `auth.getStatus`。必须有正向登录证据及非空身份字段，否则返回身份未知；官方订阅与 API Key / Gateway 分开。Copilot 遵循已有环境 Token 优先级，不因显式来源失败而借用其他账号。环境来源的有效凭据参与本机摘要，但原值与原始 Token 哈希不出原生层。

Tokage 不为本节点打开新的钥匙串 / 浏览器 Cookie / 未核实认证文件，也不执行登录、续期、切换账号或写回官方凭据。CLI 自持凭据。CLI 状态未公开的组织 / 工作区 / 脱敏显示标签留空，不声称已确认。CLI 自管凭据在同一账号下的无可观察轮换尚不能被这些状态命令完整识别；各家完整凭据来源与轮换检测仍由 U3 验证，不能把当前元数据当作所有认证变体支持。

每次专门查询前读取当前普通 shell 环境，在原生侧解析所选可执行文件；不通过全量探测或前端账号 ID 选择认证。查询前后重新核对来源，结果与权限 / 身份 / 配置代际不符即丢弃。原生收到 Provider 启用状态或路径设置时立即更新控制镜像，不等待异步数据库 writer；代理保存、全量 / 单卡重扫、设置导入均使旧绑定失效。在途任务收到取消通知，前端收到正常的绑定失效事件。

对已有额度身份绑定的正常模型派发，在启动 CLI 前重新核对来源；正在运行的 turn 保留原环境。来源变化或无法确认会暂停，防止静默换号。为避免切换到不支持订阅额度的 API Key 后无法恢复正常对话，用户可在官方 CLI 核对登录后点击卡片上的「重扫并确认此 CLI 登录来源」：只有正常探测 READY 才确认本次进程的派发来源，仍不恢复任何额度可信状态、不替用户登录、不授予新的工作区权限。自动启动扫描不作这项确认；后续新的额度绑定会重新启用身份核对。此入口确认的是现有 CLI 的可用来源，不声称已取得远程稳定账号 ID，也不是新增账号管理。

旧 Provider 缓存和旧日志属于未绑定历史，继续可读，但不进入新额度消费者；旧任务的用量、报告、成本、学习归属均未重写。身份变化只可条件恢复旧 `QUOTA_SOFT`，原生单写线程用 SQL 的状态 / 原因条件更新，避免读后写竞态清除 HEALTH / AUTH / BUDGET / QUOTA_HARD。未知来源不会被解释为新账号有完整额度。

## 共享调度与网络

手动和后续自动调用使用同一 QueryRequest / QueryResult、同一发布和缓存更新路径。每个当前 CLI 查询资源合并一个在途任务，全局最多两个；当前已接入来源互不共享厂商余额资源。未来若 U3 引入跨 CLI 的同一余额资源，需为该来源明确共同资源键，不能仅因展示在两张卡片就重复查询。

查询由独立原生任务持有，不因最后一个界面调用方消失而悬停；权限撤销、配置失效和截止仍会被处理。总截止从入口准备开始计 30 秒；CLI PTY / 原生子进程沿用回收守卫，所有查询复用所选 Provider 的代理准备，失败不降级直连。

手动最低 15 秒间隔；自动请求在有效快照内可使用缓存。通用有效期 10 分钟，具备账号范围且达到 80% 时 3 分钟。失败指数退避，普通网络退避最长 30 分钟；429 的 Retry-After 秒数 / HTTP 日期优先，手动不能绕过。401/403 阻断当前来源绑定的后续查询，不自动换凭据；来源变化或正常重扫建立的新上下文重新处理。查询失败不产生模型失败事件，不作为推理服务健康故障。

这里提供自动请求的统一入口与缓存策略，尚未恢复定时 / 闲置 / 网络恢复调度器；这些属于 U4。新权限开启后不会因此自动调用模型。

HTTP 传输目前只枚举 `GET https://api.deepseek.com/user/balance` 这一已冻结资源，不接收任意 URL。使用系统 curl 的普通参数数组，禁用 curlrc，限制 HTTPS、连接 5 秒 / 总 20 秒及输出大小，不关闭 TLS；所有重定向拒绝。认证头只经 stdin 配置传入，不放 argv / 通用环境 / 日志；不带 Cookie，不转发模型 Key 环境变量，复用配置代理及 CA。响应只在内存中按状态分类与 JSON 解析，无原文落库。U3f 尚未接入有效 OpenCode / DeepSeek 凭据解析，因此当前没有真实产品 HTTP 额度请求。

## 能力元数据与用户状态

发现目录新增独立的 usageQuery 元数据，正式 CLI 的 providers list 也返回该字段；它与对话 adapter / 旧 USAGE_QUERY 位不同。设置页不再维护六个 CLI 的硬编码名单，而按查询方法、身份接入状态和认证范围决定入口。

- Claude / Cursor / Copilot：标为需要当前身份，查询成功仍取决于真实命令公开字段；本节点没有新增实机通过声明。
- Codex / Antigravity / Reasonix：现有命令保留在原生内部，但有效身份来源尚未验证，当前在线入口暂停，保持身份待适配。
- OpenCode / Kiro：查询适配待完成。OpenCode 仅预留官方 DeepSeek HTTP 资源，Kiro 不推断新版引擎兼容。
- 其余范围外 CLI：不支持本轮在线查询。

失败、历史数据和身份未知在卡片区可见；余额按币种独立显示。来源未知、过期、无分母或 scope 不适用返回 null，模型匹配跳过未知输入，不再用 `?? 0` 或 `pct > 1` 推成零 / 百分之百。旧账号的额度等效成本投影不再作为账号状态输出，金额成本参数不能推断订阅余额。原生额度恢复也不再在缺数据时自动认定额度恢复。由于旧桥接窗口均缺少可靠 scope，现阶段可展示但不提供可用于自动额度熔断的账号比例；U3 必须明确各来源范围后才能激活该消费者。

## 验证与失败记录

机器可读摘要、源码指纹与结果见 [U2 证据](reliability-evidence/cli-usage/u2.json)。全部是离线开发验证：

全量前端 66 文件 / 453 项通过；原生 352 通过 / 28 ignored，桌面库 22 项、存储 38 项、正式 CLI 离线 21 项通过。类型检查与生产构建通过，i18n 1788 keys、隔离及 IPC 接线（136 commands / 0 无生产调用）通过。最后的身份上下文字段核对已复跑同一原生集合，仍为 352 通过 / 28 ignored；结果归档到上述证据。

- 契约 / 服务 / HTTP 专项覆盖 1% / 100%、nullable、同周期模型、多币种精度、旧缓存、身份 / 配置竞态、持久化失败回退、错误脱敏、401/403、429 日期 / 秒数、并发合并及最后一个调用方消失后的撤销。
- HTTP 协议测试通过测试文件内 PATH 里的 curl 替身走正常传输函数，检查固定 HTTPS 目标、无跳转 / insecure、Bearer 只在 stdin、模型 Key 不进入环境。不是厂商网络成功或账单验收。
