## 本轮两个目标组合

以下字段与界面使用的 [范围数据](../src/lib/reliabilitySupport.json) 一致。版本是本轮复验目标及历史记录版本，不是“已验证当前安装版本”；本节点未发起模型请求或更改登录。

- **CLAUDE_CODE**：macOS arm64，CLI **2.1.296**，模型请求 **`haiku`**；官方订阅登录（不含 API Key / 自定义 Gateway）。当前会话明确授予 Full Auto，执行使用独立 Git worktree，保留适用的系统沙箱与逐回合恢复保护。`haiku` 是 CLI 请求别名，不承诺服务端永远指向同一模型；m2b 必须记录实际模型和版本。
- **OPENCODE**：macOS arm64，CLI **2.0.29**，模型请求 **`deepseek/deepseek-flash`**；OpenCode 凭据存储中的 DeepSeek 官方 API Key（不含自定义 Gateway / 其他模型）。当前会话明确授予 Full Auto，执行使用独立 Git worktree，保留适用的系统沙箱与逐回合恢复保护。不回退模型或服务商。

Full Auto 是应用会话授权，不表示各 CLI 原生权限机制相同，更不代表审批回调已验收。m2d 仍须验证拒绝、等待、取消和恢复。只读规划 / 审查与可写执行按角色限制；系统沙箱能力不能推导出支持 Linux / Windows。现有桌面脚本使用 `maxParallel: 1`，不能作为并行需求证明。

目标选定不修改用户默认模型、路由、授权或隔离设置，不自动安装 / 降级 CLI。如果版本已变化，重新记录确切版本并复验，不能把声明兼容版本范围视为验收范围。

## 四级证据：分别保留

两个目标组合的状态如下，每级均独立判断：

- **代码已实现**：两个 provider 均注册对话适配器及生产 `run_turn` 路径，具备角色链、原生会话读取和桌面执行入口；不意味着每种能力或失败路径已经实机覆盖。
- **替身 / 本机回归通过**：m1g 记录前端 251 项、Rust 555 项通过；m2a 的界面回归与原生回归结果见下方。fixture / fake / 本地契约测试不是远端模型通过证明，ignored 不计通过。
- **真实 CLI**：2026-10-15 的两个目标版本均有角色链通过的历史记录；**当前 m1 改造后的代码仍待复验**。历史入口与范围见 [CLI 进度记录](../cli-support-todo.md)，不将 `/tmp` 路径视为永久可复现的原始证据。
- **桌面全链路**：2026-10-15 有固定用户编辑计划、两级 DAG / worktree / gate / 合并的历史记录；**自然语言输入 → 自动规划 → 独立验收 → 最终交付在当前代码上待 m2b 验收**。固定任务 fixture 不算自动规划验收。

当前没有组合获得“当前版本真实 CLI 通过”或“当前自然语言桌面全链路通过”的认证。m2a 的范围公开完成与这些验收尚未完成可以同时成立。

## 界面口径与更新约束

CLI 设置卡片显示探测不等于验收、目标平台 / CLI / 模型 / 认证 / 会话授权 / worktree、历史证据日期、当前 CLI 与自然语言桌面均待验证。非目标显示“未选入本轮”；顶部 CLI 状态菜单同样声明 READY 的边界。检测版本缺失、升级或任何与记录不完全相等的字符串均明确提示未验证；即便精确匹配，仍不自动升级当前验收状态。目标字段表示候选范围，不表示当前机器、账号或配置满足范围。

数据入口为 `src/lib/reliabilitySupport.json`；中英文文案为 `src/i18n/locales/{en,zh}.ts`。后续改为通过前必须新增包含应用提交、OS build、确切 CLI / 请求与实际模型、认证渠道（不含密钥）、授权与隔离模式、原始需求 / 计划版本 / 独立 gate / 交付提交的证据，并同时更新界面文案和文档，不能仅改 JSON 状态。模型自动路由或版本变化后，旧通过只保留为历史。
