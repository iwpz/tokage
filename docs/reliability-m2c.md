# m2c：复杂 Git 状态与增量需求

验收日期：2026-10-19。范围为本机真实 Git 场景、前端编排回归，以及 OpenCode 的真实桌面正常路径复验。m2d、m2e 尚未验收。

## 实现与结果

- 保护用户已有暂存、未暂存及未跟踪内容，覆盖项目子目录和执行期间继续编辑。交付绑定最初目标分支完整引用及 HEAD；切换到相同提交的另一分支、新提交或脏检出均拒绝自动合入。
- 真实并行任务先进入集成分支，下游 worktree 能读到两个上游结果；最终合入提交的第二父节点等于已验收源提交。真实冲突只撤销本次产生的冲突合并；用户原有冲突和 index.lock 保留，普通 Git 故障不会因分支名包含 conflict 被误分类。
- 计划保存保留结构化版本、模型参数及历史，确认新版后归档旧用户编辑稿。重规划比较实际执行输入，变更任务、契约消费者及其下游重新执行；独立任务的报告来源显式继承。旧计划提案和旧验收证据不能为新需求背书。已经合入的任务不能靠删除记录撤销，必须增加明确撤销任务或建立新会话。
- 全量 gate 和三种交付均绑定计划、任务状态和源代码证据。子目录项目在正确 cwd 验收。导出使用固定基线与源提交，二进制补丁按原始字节保存，拒绝覆盖现有输出。
- 补丁还原覆盖二进制、非 UTF-8 文件内容、CRLF、空格及中文文件名、可执行位、内部符号链接、重命名和删除；还原后的索引树与源提交树完全一致。
- 合入、导出补丁、保留分支均记录源分支及提交。清理不强制删除，分支变化、脏文件或验收后新增人工提交均拒绝清理，保留恢复元数据；补丁导出后仍可选择合入或保留分支。

## 边界

- 旧会话缺失交付基线、目标绑定或执行计划标识时拒绝自动交付，需重新规划执行或人工恢复；不会推测安全基线。
- 本节点验证操作前状态检查及单进程交付互斥，不承诺跨进程原子性。计划多文件保存、强杀恢复、并发 Git 操作与幂等性仍属于 m2d/m2e。
- 忽略文件、非 UTF-8 文件名、子模块和外部符号链接不在本次补丁文件类型验收范围内。
- 生产 IPC 检查仍有 m2f 已登记的 5 个无生产调用命令；本节点没有将该检查记为通过。通过 m2c 不代表整个 M2 或日常可靠性已经通过。
