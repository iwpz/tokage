## 保留范围与限制

Debug Provider、演示模式、浏览器预览 Mock 是已存在且有产品入口的功能，并非九次验收专属补丁，本次未删除这些功能，也未将整个 IPC 模块重写。真实验收必须关闭调试输出且排除演示身份；这几条路径的结果不能用于真实模型可靠性结论。

Rust `#[cfg(test)]` 下的协议 fixture、崩溃注入、Fake CLI 与相邻组件测试继续保留。历史需求编号注释、证据内字符串不属于运行时例外。移除特殊入口不等于删除所有测试代码。

当前没有完整的外部无人值守 UI 自动化；新流程允许可复核的人工正常界面步骤，明确记录人工操作和证据缺口。若关键流程无法观察则阻断，不能重新嵌入驱动来通过验收。准备器隔离 App 和 WebView，不能隔离 CLI 的 HOME / 账号记忆；完整隔离须专用 OS 账号。

旧统计仍为 9 项交付、5 项历史自主交付、4 项辅助 / 接手。原始事实不改，但旧数据只代表 `legacy-internal-driver` 下的交付，不能追认为新 `external-ui-v1` 或默认设置无注入验收通过。第十项使用新协议单列统计。
