# T04 · 费用、估价与对照追溯

日期：2026-11-01。范围：离线实现与回归验证；无真实模型请求、真实账号账单验证或本轮桌面 UI 人工验收。

## 查询与数据边界

App 的生产 `get_usage_dashboard` 调用在当前显式数据目录内，将旧 `usage_events` / `usage_receipts` 与 `runtime-v1/tokage.db` 的共享运行快照投影为一个只读视图。质量与费用使用同一次读取的 runtime 快照。旧数据库读取使用读事务，runtime Reader 使用自身一致性读取；两数据库间没有跨库原子事务，不承诺同一瞬间的全局快照。

不补写旧用量、不迁移结算、不触碰个人数据，不扫描 CLI 默认目录。CLI 新增 `run accounting --id`，只读取用户选择的数据目录中的该 run。人工接手回执是正常产品写入能力，与只读统计分开。

## 费用口径与归因

- `reportedUsd`：非 ESTIMATED 来源的 CLI 报告美元值，不等于发票或供应商实付认证。
- `estimatedUsd`：冻结知识包的 token 等效估价，或明确标记的 CLI ESTIMATED 值；不当实付、不混入报告美元。
- 原生 tokens、credits、premium requests 保留单位、来源，后两者不转换成美元或 token。图表仅显示已报告 token，估算 token 在投影及逐条证据中独立保留。
- 新 turn 创建时冻结价格、config/pack 依据与阶段。PLANNING / EXECUTION / REPAIR / REASSIGNMENT / REVIEW 独立计入；任务报告包含在所属调用的 token/费用内，不额外编造一笔。普通旧会话的 DIRECT / CONTEXT 等原始阶段保留。
- 修改预算、模型或知识包不会重定价已有轮次。历史无冻结价格时估价未知；历史无冻结阶段时只在已有证据允许时识别修复，否则标为 EXECUTION_HISTORY_UNKNOWN。动态价格表、多请求且长上下文档位未知、缺缓存费率、观测模型不同等情况不猜价。
- 以 `turn:<id>` 统一 keyed 回执；重复来源合并一次并列出证据引用。身份、token、已知美元、source 或原生单位冲突时 fail closed；无幂等键的旧数据使用独立行 ID 并标为未核验，不能声称已证明其没有历史重复。
- 缺费用不补零；完整总额可为 null，已知小计与缺失条数单列，明确的零保留为零。日期损坏的回执保留为日期未知，不填入某周期，相关总额标为不完整；不会回退到全历史金额。金额、原生单位非法或聚合溢出时查询明确失败。

旧用量表不保存 premium requests，也不能恢复已经丢失的字段或证明默认零 token 当时确实被 CLI 报告；这些历史限制不通过本轮重写掩盖。Receipt 的来源、run/task/turn、冻结价格和摘要可在看板下钻，CLI 返回原始投影。

## 对照与人工成本

旧 ASSIGNMENT / DIRECT / CONTEXT 范围可能重叠，且旧结算曾混用估价与报告金额，因此不再汇总为“节省美元”。原始行与 detail 保留；`savings.totalUsd` / `byKind` 数值为 null。

仅已结算、数值有效、basis=`first_turn_counterfactual_v1`、horizonTurns=1 的 CONTEXT 行显示有符号基线差额。负差额原样展示，未结算和历史依据不明分别标记。对照基线仍是估计，不能称为实测现金节省；未建立同任务、同验收的强模型对照，不宣称优于强模型。

人工接手增加可选申报用时：App 输入分钟，CLI `--effort-seconds` 输入非负整数秒。0 与未申报不同；记录在手工接手回执上，不制造成功模型调用。不从等待时长推测劳动、不折算美元。已知日期的周期申报值汇总，旧无日期/无用时的记录单列未知。

## 验证与限制

验证覆盖价格/缓存/长上下文、历史价格不重算、读取重放、报告美元与估价及原生单位分离、缺失与零、重复与冲突、溢出、日期损坏、负差额及未结算、人工用时持久化、CLI 公开查询与接手参数、前端显示和公共命令字段编码。

实际命令、日志、失败与修复记录及源文件哈希见 [验证清单](reliability-evidence/t04/verification.json)。前端全量、共享 runtime 全量加最终差异回归、App 全量加最终差异回归、CLI 全量均使用离线测试；编译与单元结果不是桌面视觉验收。真实账号、跨平台与后续日常可靠性样本不在本轮结论内；Claude 未安装不通过模拟夹具冒充实测，9/20 与其他 TODO 状态保持原口径。
