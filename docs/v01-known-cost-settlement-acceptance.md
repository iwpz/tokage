## 热报告和原始消息

- 在独立合成 Git 项目中执行只读直聊。启用 Suggest、缓存估价及热报告。简报上限设为 900 token，报告上限为 300 token。两轮普通对话后，带有合成分隔符的长消息触发可见内容估计。窗口预计占用超出 180,000 token 阈值，界面建议带上下文开新窗口，且估计缓存仍可复用。
- 在桌面接受 FRESH 建议，再发送登记的多行原文。原线程生成一次报告，五节均有正文。新线程收到来源为 `GENERATED_MODEL_REPORT` 的 1,200 字节摘录及截断标记。113 字节的原始消息在 Tokage 记录和解码后的 Aider 新线程历史中一致，只发送一次。桌面收到新窗口的预期回复。
