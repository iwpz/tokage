## 操作和观察

1. 在「添加项目」的 macOS 选取器中激活 Tokage 窗口，按 `⌘⇧G` 输入隔离克隆的绝对路径，回车进入目录，再点击「打开」。界面显示正确的克隆路径并打开授权对话框。随后信任这个隔离工作区，在隔离应用中只允许 Codex CLI。先前逐键向后台选取器输入未生效，这次使用前台系统按键与原生「打开」按钮完成选择。
2. 选择 Codex GPT-6-Luna Medium，使用只读直聊。Context 设为 Suggest，缓存估价与热报告开启，保留 15% 阈值，Debug Provider 与 Demo 均关闭。首轮完成后界面建议继续当前窗口，显示还需一个完成轮次才能离开冷却。第二轮在同一线程审阅登记过的仓库源码材料，随后界面显示 `Compact suggested`，说明下一轮会携带进展开启新窗口。
3. 点击 `Apply next turn`，再发送登记过的短问题。第一次排队写入动作 1（`COMPACT / SUGGESTED`）。当时系统估计缓存仍热，当前来源没有完整报告。发送后动作 1 被撤销，Tokage 在旧线程发起一次额外的报告轮。实际报告的五个标题顺序正确，每节有正文。
4. 报告完成后，动作 2 以 `COMPACT / APPLIED` 记录，执行方式为 `fresh`。新线程的第一条任务是保留简报、完整报告、分隔符和原始问题，实际请求与预期逐字节一致。简报标记为 `GENERATED_MODEL_REPORT`，记录的报告来源与原线程一致。桌面界面随后显示带保留上下文的回复已完成。
